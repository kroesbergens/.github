# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately to
**security@kroesbergens.com**. Do not open a public GitHub issue.

Include:
- A description of the issue and the impact you believe it has.
- Steps to reproduce, or a minimal proof of concept.
- The repository, branch, and commit (or release) you observed it on.

We will acknowledge receipt within two business days and aim to provide
a triage assessment within five business days.

## Supported versions

Only the latest released version of each project receives security
fixes. Older versions are not maintained.

## Coordinated disclosure

We will coordinate disclosure timelines with you once the issue has
been triaged. Please give us reasonable time to remediate before any
public disclosure.
